Comment l'import fonctionne

  • La feuille utilisée est celle dont le nom contient « suivi » (hors dossiers partis).
  • La ligne d'en-têtes est détectée automatiquement : la colonne A doit contenir « N° ».
  • Chaque ligne devient un dossier suivi ; NOM DOSSIER est obligatoire.
  • Les étapes acceptent une date (jj/mm/aaaa), « X » (fait sans date) ou un texte libre (fait + note).
  • Les lignes sans nom de dossier sont ignorées et signalées dans le rapport final.
  • Les types reconnus : Création, Reprise, Revision — le pipeline d'étapes s'adapte.
